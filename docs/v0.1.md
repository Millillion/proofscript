# ProofScript v0.1.0: Definition of Done

v0.1.0 is the first full MVP: the version we publicize. Until then, work ships as **patch releases** (0.0.x), one at a time: each is a git tag plus a GitHub release with a [CHANGELOG](../CHANGELOG.md) entry. Nothing is published to npm until 0.1.0.

v0.1.0 is done when every box below is checked, CI is green, and Jordan has done the syntax review and gone through the [review queue](review-queue.md). Each box names the test or example that proves it.

## 1. Dependent types and theorem proving

- [x] Inductive data types from discriminated unions (`good-list`, `typescript-only/list.ts`)
- [x] Inductive propositions (`typescript-only/even.proof.ts`)
- [x] Theorems with Lean tactics and term proofs, kernel-checked, with axiom footprints (`check.test.ts`)
- [x] Value-indexed types: `n extends nat` indices, `typeof x`, `Vec<T, n>`, `Fin<n>` (fixtures `good-indexed`, `bad-indexed`) — 0.0.4
- [x] Structures (plain object types) in the logic (fixture `good-struct`) — 0.0.2
- [x] `examples/math`: a library of list, arithmetic and sorting theorems (28 theorems) — 0.0.5

## 2. Program verification

- [x] Preconditions and postconditions (`good-post`, `bad-post`)
- [x] Loops with invariants and termination; read-only arrays with proved-in-bounds indexing (`good-loop`, `bad-loop-*`)
- [x] Integer overflow obligations (D32) (fixtures `good-overflow`, `bad-overflow`) — 0.0.1
- [x] Mutable arrays and objects with frames: `Modifies`, `Old`, `Holds` (D21) (fixtures `good-mutation`, `bad-alias`, `bad-undeclared-modify`, `bad-old`, `bad-write-oob`) — 0.0.3
- [x] Strings (fixture `good-string`) — 0.0.2

## 3. Usable by others

- [ ] `npm install proofscript` and `npx proofscript check`, with the pinned Lean toolchain and lean4export set up automatically. Done, verified from a packed tarball in CI (0.0.8); publishing to npm remains, at 0.1.0.
- [x] Proof certificates: CI checks proofs without Lean, with each certificate bound to its TypeScript statement (`certificate.test.ts`) — 0.0.6
- [x] `proofscript audit`: trust footprints per theorem and per project (`audit.test.ts`) — 0.0.7
- [x] Getting-started tutorial and reference docs ([tutorial](tutorial.md), checked as `examples/tutorial`; [reference](reference.md)) — 0.0.7

## 4. Evidence

- [x] Lean Kernel Arena: 235 passed, 0 failed, 3 declined ([status](status.md))
- [x] Differential mutation fuzzing against Lean's kernel
- [ ] `examples/base64`: a verified drop-in replacement for `base64-js`, passing its original test suite, with the round trip `decode(encode(x)) = x` proved. 0.0.8: drop-in, suite passing, safety and the unit and group round trips proved; the whole-array round trip as one theorem remains.
- [x] Red-team suite covering every gap closed above (`bad-*` fixtures, forged certificates, `bad-caller`, `boundary`, the arena's soundness bugs) — 0.0.8
- [x] CI runs unit tests, checker fixtures (with Lean), and a light arena subset — 0.0.8

## 5. Review

- [ ] Jordan's syntax review (D29), against `examples/math`
